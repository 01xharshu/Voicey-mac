## Kokoro neural speech

Kokoro-82M v1.0 model and voice embeddings by hexgrad: Apache-2.0. Converted model package `kokoro-multi-lang-v1_0` supplied by k2-fsa/sherpa-onnx. Michael speaker 16, Heart 3, Bella 2, Emma 21. Model package LICENSE remains in Resources/Kokoro. Pinned asset hashes and official download URLs are in scripts/prepare-neural-speech.py.

Native inference: sherpa-onnx v1.13.8 (Apache-2.0), ONNX Runtime (MIT), two CPU threads. The public C header is copied unchanged from the pinned runtime distribution. The runtime uses eSpeak-NG for phoneme conversion (GPL-3.0) and piper-phonemize (MIT); their license texts are included in Resources. This dependency set is not entirely MIT/Apache. Preserve all license notices and satisfy the applicable copyleft/source obligations before distributing combined binaries. No public distribution or repository license change is performed by the local build.

Corresponding upstream sources and pinned phonemizer revisions:
- https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.8
- https://github.com/csukuangfj/espeak-ng/tree/ed530aa113046142eb5115cf2fc9157854d0ffe1
- https://github.com/csukuangfj/piper-phonemize/tree/f3ff95afc03640bc1399e113e83361192a2fafb4
- https://github.com/microsoft/onnxruntime

The phonemizer supplies pronunciation; audio is generated by Kokoro neural inference, not eSpeak's synthetic voice. All synthesis is in-process. Text and generated speech stay in memory. The model is bundled for offline playback; no automatic speech-time download is performed.
