# Voicey landing page

Static, responsive HTML/CSS. Open `index.html` directly or serve this directory:

```sh
python3 -m http.server 8080 --directory web
```

No build step, JavaScript, tracking, account, external fonts, or remote image requests. GitHub buttons point to the repository origin: https://github.com/01xharshu/Voicey-mac . The visual is a CSS illustration, labeled accordingly. Content describes implemented capabilities and discloses current local-build limitations. Honors reduced motion and includes keyboard focus/skip navigation. This directory can be hosted as-is on any static host.
