LOCAL MEANS LOCAL.

Your assistant.
Your Mac.
Your business.

The intelligence runs here.

Voicey embeds llama.cpp and whisper.cpp inside the native application. Once the models are installed, reasoning and speech recognition work offline.

  • No cloud AI or remote inference server.
  • No account, analytics, or telemetry.
  • Microphone audio stays in memory by default.
  • Explicit memories are stored locally and remain editable.
THE INITIAL MODEL PAIRQwen3 1.7B + Whisper base

About 1.43 GB of model downloads, with verified checksums. Runtime memory is additional. This build uses CPU + Apple Accelerate.

An evolving local build.

Voicey is a source-built local application. The current bundle is ad-hoc signed, not notarized. Live microphone quality, physical-key behavior, and additional hardware need manual QA. Website URLs require approval; destructive actions and unrestricted scripts are unavailable.
